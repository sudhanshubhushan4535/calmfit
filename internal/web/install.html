Add CalmFit to your home screen

Android (Chrome)
  1. Open this page in Chrome.
  2. Tap the ⋮ menu at the top right.
  3. Tap Install app (or Add to Home screen), then Install.
iPhone (Safari)
  1. Open this page in Safari (other iPhone browsers can't install it).
  2. Tap the Share button (the square with an arrow).
  3. Scroll down, tap Add to Home Screen, then Add.
  4. Open CalmFit from the new icon. Workout reminders only work on iPhone when opened this way.
